## What this app is

Story Engine — a reader for books the reader moves through: passages, choices, carried state and a
trail of where you have been.

It runs on your own device. There is no account, no server and no sign-in.

## What it collects

**Nothing.** No analytics, no telemetry, no crash reporting, no fingerprinting, no advertising
identifier, no email capture.

There is no code in it that reaches a host outside your device: no `fetch`, no socket, no script
loaded from another host. The test suite asserts this rather than trusting it.

## What is stored on your device

Your place in the book — the passage, what you carry, and the trail — is kept in the app's own
storage on this device, and nowhere else. A reading you export is a file you chose to download; it
is yours and the app keeps no copy.

## Links that leave the app

The landing page links to the source repository and to the download page. Opening one takes you to
that site, with its own privacy policy; the app loads nothing from it.

## Erasing

Clear the app's stored data, or delete the app itself. Nothing is held anywhere else, so there is no
other copy to ask us to remove.

## Changes

If a future version ever adds a request that carries your data, this file changes in the same commit.
